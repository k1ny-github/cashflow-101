# CASHFLOW — банкир

Финансовый отчёт для настольной игры «Денежный поток 101» Роберта Кийосаки.
Заменяет бумажный бланк: считает денежный поток, наличные, активы и пассивы
за всех игроков за столом.

Ни сборки, ни зависимостей, ни сервера. Три файла и `index.html`.

## Как запустить

**На телефоне и ноутбуке через GitHub Pages**

1. Залить содержимое папки в репозиторий.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Открыть выданный адрес. Работает офлайн после первой загрузки.

**Локально**

Открыть `index.html` двойным щелчком — этого достаточно.
Если нужен адрес в локальной сети, чтобы зайти с телефона:

```bash
npx --yes serve .
```

## Как устроено

Приложение хранит не «текущие цифры», а **журнал операций**: выбрал профессию,
купил акции, получка, взял кредит. Все числа отчёта каждый раз пересчитываются
из этого журнала с нуля.

Отсюда три полезных свойства:

- **Откат любой строки задним числом.** Удалил операцию из середины журнала —
  все последующие ходы пересчитались сами.
- **Цифры не могут разойтись.** Пассивный доход, общий расход и денежный поток
  нигде не хранятся, они выводятся из списка активов и пассивов.
- **Автосохранение.** Закрыл вкладку, вернулся через день — партия на месте.

Файлы:

| Файл | Что внутри |
|---|---|
| `professions.js` | Карточки профессий и список личных долгов |
| `engine.js` | Правила игры: чистые функции, никакого интерфейса |
| `ui.js` | Экраны, формы операций, журнал, хранение |
| `index.html` | Разметка и стили |

## Правила, зашитые в движок

Ссылки на страницы русской книги правил CASHFLOW 101.

- Стартовые наличные — месячный денежный поток плюс сбережения (стр. 2).
- Покупка недвижимости и бизнеса: наличными платится только первый взнос;
  выплаты по ипотеке уже учтены в денежном потоке карточки и в расходы
  не вносятся (стр. 6).
- Продажа: финансовый результат = цена продажи минус ипотечный кредит (стр. 7).
- Акции, фонды и депозиты оплачиваются полностью наличными; дивиденды идут
  в строку «Проценты/Дивиденды» (стр. 8).
- Банковский кредит кратен $1000 под 10 % в месяц; выплаты — только проценты
  и тело долга не уменьшают. Личные долги гасятся целиком, банковский —
  частями по $1000. Налоги, прочие расходы и расходы на детей уменьшать
  нельзя (стр. 9).
- Ребёнок: лимит трое на игрока (стр. 4).
- Благотворительность: 10 % общего дохода, три хода с двумя костями.
  Увольнение эти привилегии отменяет (стр. 4).
- Увольнение: платишь сумму общего расхода, пропускаешь два хода (стр. 4).
- Выход на дорожку открывается, когда пассивный доход превысит общий расход.
  Подъёмные — пассивный доход, округлённый до ближайшей тысячи, умноженный
  на сто. Цель победы — подъёмные плюс $50 000 (стр. 11).
- На скоростной дорожке кредиты в банке недоступны (стр. 11).
- Благотворительность на дорожке: разовый взнос по карточке (по умолчанию
  $100 000), после которого до конца игры можно на каждом ходу выбирать,
  кидать одну, две или три кости (стр. 12).
- Мечта выбирается в начале партии (стр. 2). Победу приносит покупка
  **своей** Мечты — чужая игроку не принадлежит. Попав на чужое розовое
  поле, игрок ставит жетон: платить не надо, но цена этой Мечты для её
  владельца растёт на 100 % от первоначальной стоимости за каждый жетон,
  то есть цена = база × (1 + жетоны) (стр. 12).

## Чего пока нет

- **Карточки Медсестры.** В списке одиннадцать профессий из двенадцати —
  цифры Медсестры найти не удалось. Добавляются одной строкой
  в `professions.js`.
- **Автоматической процедуры банкротства.** Приложение только предупреждает
  и отсылает к стр. 10; продажи активов банку вводятся руками.
- **Сделок между игроками.** Правила их разрешают (стр. 3), но за столом
  так не играют. При необходимости — двумя разовыми операциями.
- **Синхронизации между устройствами.** Каждое устройство ведёт свою партию.
  Партию можно передать через `⋯ → Выгрузить игру в файл`.

## Сверка данных

Цифры врача сверены с карточкой из книги правил: доход $13 200, расход $9 650,
поток $3 550. Остальные десять профессий перенесены из более раннего прототипа
и заслуживают сверки с карточками — править их в `professions.js`.
