# CASHFLOW — банкир

Локальный финансовый отчёт для настольных игр «Денежный поток 101» и
Cashflow 202. Приложение считает наличные, доходы, расходы, активы и пассивы,
а все изменения хранит в журнале операций с откатом через повторный расчёт.

Ни сборки, ни зависимостей, ни учётной записи не требуется: это статическое
приложение из `index.html` и локальных JavaScript-файлов.

## Как запустить

**Локально**

Откройте `index.html` двойным щелчком. Для доступа с телефона в той же сети:

```bash
node serve.js
```

**Через GitHub Pages**

1. Разместите содержимое папки в репозитории.
2. В Settings → Pages выберите `Deploy from a branch`, ветку `main` и `/ (root)`.
3. Откройте выданный адрес. После первой загрузки партия сохраняется локально
   в браузере.

## Режимы

- **Cashflow 101** сохраняет прежние правила и отчёт 101.
- **Cashflow 202 Standard** использует официальный срок биржевого опциона в
  три тура и стандартные лоты от 100 до 5000 акций с шагом 100.
- **Cashflow 202 Custom** позволяет выбрать положительное целое число туров
  для опциона. Нестандартный лот разрешается только после явного подтверждения.

Режим фиксируется после добавления первого игрока. В 101 интерфейс скрывает
инструменты 202.

## Журнал, сохранение и перенос партии

Приложение хранит не готовые итоги, а журнал операций. Наличность и весь
финансовый отчёт каждый раз пересчитываются с начала журнала. Поэтому:

- удаление операции откатывает её и пересчитывает последующие ходы;
- правка принадлежащей игроку карточки записывается отдельной операцией и тоже
  откатывается;
- автосохранение сохраняет режим, настройки, журнал, выбранного игрока и
  незавершённый стартовый портфель;
- выгрузка и загрузка JSON доступны через меню `⋯`;
- повреждённая операция не удаляется и не переписывается: партия загружается,
  а интерфейс показывает предупреждение с номером операции.

**Синхронизации между устройствами нет.** У каждого браузера своя локальная
копия партии. Для переноса используйте `⋯ → Выгрузить игру в файл`, затем
загрузите файл на другом устройстве.

При одновременной игре на разных устройствах каждый записывает свою сторону
сделки. Для недвижимости, обязательной передачи бизнеса и внешних жетонов
Мечты журнал показывает короткий код `CF-…`, по которому игроки сверяют записи.
Общую карточку рынка 202 необходимо внести с одинаковыми параметрами на каждом
устройстве. Физическая доска остаётся источником порядка опционов и доступности
невыбранных Мечт.

## Поведение Cashflow 101

- Стартовые наличные — месячный денежный поток плюс сбережения.
- При покупке недвижимости или бизнеса наличными платится первоначальный
  взнос; ипотека равна цене минус первоначальный взнос и уже отражена в
  денежном потоке карточки.
- Продажа недвижимости даёт цену продажи минус остаток ипотеки.
- Акции, фонды и депозиты оплачиваются полностью; дивиденды входят в пассивный
  доход.
- Банковский кредит берётся частями по $1000 под 10 % в месяц. Личные долги
  гасятся целиком, банковский кредит — частями по $1000.
- Выход на Скоростную дорожку доступен, когда пассивный доход превышает общий
  расход. Условие победы 101 сохраняет прежнюю логику приложения.

## Официальное поведение Cashflow 202

### Старт и Крысиные бега

- Игрок начинает с карточкой профессии, выбранной Мечтой и явным стартовым
  инвестиционным портфелем. Портфель записывается одним событием вместе со
  снимком профессии.
- Поддерживаются call/put-опционы, страддлы, отдельные сроки каждой позиции,
  короткие позиции с банковским конвертом, рыночная цена, сплиты, обратные
  сплиты и банкротство компании.
- Первая следующая рыночная цена фиксирует обязательное закрытие шорта. Убыток
  по шорту нельзя покрыть новым банковским кредитом.
- Поддерживаются опционы на недвижимость, D2Y, постоянная страховка,
  погашение ипотеки, продажа части земли, равнотипный обмен недвижимости,
  роялти и разрешённые сделки между игроками.
- Выход на Скоростную дорожку требует пассивный доход **не меньше двойного
  общего расхода**.
- При личном банкротстве 202 приложение показывает активы и автоматически
  рассчитывает выручку Банка; D2Y и роялти сохраняются. После банкротства
  банковский кредит ограничен обязательными расходами и увольнением.

### Скоростная дорожка 202

- Бизнес покупается за полную цену наличными. Первоначальный взнос и ипотека
  сохраняются как данные физической карточки, но не определяют списание.
- Попадание на чужой бизнес означает обязательный выкуп по базовой цене,
  умноженной на число жетонов владения после передачи. Повторное попадание на
  свой бизнес может добавить одну франшизу и её базовый доход.
- Невыбранная Мечта продаётся один раз на весь стол. Выбранная игроком Мечта
  не может быть куплена как свободная.
- Победа требует обе половины условия: прирост дохода от бизнесов не менее
  **$50 000 в месяц** и либо покупку своей Мечты, либо покупку двух различных
  невыбранных Мечт.

### Благотворительность — домашнее правило

В этой версии благотворительность на Скоростной дорожке 202 всегда стоит
**$100 000**. Это явное домашнее правило приложения, а не утверждение о цене
на любой физической карточке. После разовой оплаты игрок на каждом ходу
выбирает одну, две или три кости; изменение числа костей повторно не списывает
деньги.

## Ограничения

- Приложение не содержит полной базы физических карточек 101/202. Поддержанные
  операции автоматизированы, но неподдержанные физические карточки и их
  специальные эффекты нужно учитывать вручную через разовый доход/расход,
  прочий ежемесячный расход, счётчик карточки или правку принадлежащей карточки.
- Автоматической синхронизации, общего онлайн-стола и конфликтов нескольких
  устройств нет.
- Данные профессий перенесены вручную. Врач и Медсестра сверены с физическими
  карточками; остальные профессии стоит дополнительно проверить перед игрой.

## Основные файлы

| Файл | Назначение |
|---|---|
| `engine.js` | Свёртка журнала, расчёт отчёта и общие правила |
| `game-config.js` | Режимы Standard/Custom и их настройки |
| `market202.js` | Расчёты опционов, шортов и рынка 202 |
| `assets202.js` | D2Y, страховка и операции с активами 202 |
| `fast-track202.js` | Выход, бизнесы и победа на Скоростной дорожке 202 |
| `save.js` | Нормализация, импорт и экспорт сохранений |
| `ui.js` | Формы, журнал, автосохранение и отрисовка |
| `index.html` | Разметка и адаптивные стили |
| `tests/` | Модульные и интеграционные проверки |
